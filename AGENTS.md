# Instructions for automated agents

Scientific correctness and preservation of the longitudinal record take precedence over convenience.

- Agents may repair software. Agents must not repair scientific data.
- Never rewrite, delete, or replace historical L0 raw observations.
- Never silently change a Frozen prompt, model lock, Wave Manifest, or execution schedule.
- Never silently substitute a model or strengthen a comparability classification.
- After a Wave begins, changes require an explicit, append-only protocol-deviation record.
- A refusal, hallucination, poor answer, short answer, unsafe behavior, or unexpected response is scientific data, not a technical retry condition.
- Apply substantive protocol changes prospectively and preserve superseded versions.
- Never put credentials or restricted raw outputs into Git, logs, CI artifacts, issues, or pull requests.
