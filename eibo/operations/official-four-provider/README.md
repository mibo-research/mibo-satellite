## まだ決めないこと

70項目×4社×10反復の計2,800件と、再coding込み最大3,080件の作業量は採用済みです。
これは処理能力の実証や費用・日時・実行の許可ではなく、AIが一次採点する計画でもありません。
3か月間隔・目標18時間／上限24時間も方針として採用済みですが、容量検証や対応するschedulerの
正式対応は未確認で、具体的日時や自動予約はまだ作成しません。初回モデル候補とPerplexityの
新しい正式用途profileを作る方針も採用済みですが、実際のprofileやmodel lockは未作成です。
初回1回の予算・送信上限も採用済みですが、費用制御の実装・上界の検証は未完了です。
責任者の方針採用も完成版の承認ではありません。条件付き利用方針の採用も4社の利用可否の
最終判断ではなく、terms holdを維持します。追加ガバナンス資料を求めることは停止し、
未確認事項を保持して拠点・日時の準備へ進みます。ガバナンス雛形はPENDINGのままで、
AIが未提示の機関判断・氏名・時刻等を補完せず、最終凍結や実行許可も別です。

Googleで現在の65秒間隔を維持する場合、700回の開始間隔だけで最低12時間37分15秒です。
最終応答や遅延は別に加わり、12時間目標には収まりません。24時間以内の実行も未検証です。
quota・負荷・費用は後の調査・承認対象であり、W0の7件成功から能力を保証しません。

新たな科学的凍結と、正式用途に対応した実装・試験・モデル/profile・スケジュール・拠点等の
個別ロックがすべて揃うまでは、`FUTURE_OFFICIAL_EXECUTION_READY=false` のままです。
旧 `SCIENTIFIC_PROTOCOL_COMPLETE=true` は旧5成果物の整合性を示すだけで、
この新計画の完成を意味しません。`W0_READY` と `W01_READY` の既存判定は変更しません。
