## まだ決めないこと

既存案の70項目×4社×10反復は計2,800件ですが、未承認です。人間1名による一次codingの
作業量も含めて確認します。AIが自動的に一次採点する計画ではありません。
codingの品質確認方法、反復数、観測頻度・時間枠、モデル、Perplexity移行の正式採用、
protocol owner、利用条件、倫理・研究ガバナンス、拠点・日時、費用・送信上限を順番に決めます。

Googleで現在の65秒間隔を維持する場合、700回の開始間隔だけで最低12時間37分15秒です。
最終応答や遅延は別に加わり、12時間目標には収まりません。24時間以内の実行も未検証です。
quota・負荷・費用は後の調査・承認対象であり、W0の7件成功から能力を保証しません。

新たな科学的凍結と、正式用途に対応した実装・試験・モデル/profile・スケジュール・拠点等の
個別ロックがすべて揃うまでは、`FUTURE_OFFICIAL_EXECUTION_READY=false` のままです。
