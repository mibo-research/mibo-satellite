# EIBO Prospective Amendment 001 — Rename and solo operations

**Status:** Configured; pending attributed human attestation  
**Scope:** Prospective EIBO Waves only  
**Legacy scientific record:** Unchanged

## Decision encoded

The current project name is **EIBO**. `MIBO-Education` remains the historical name embedded in the byte-frozen v1.0 scientific artifacts and legacy Wave identifiers. Those files, identifiers, and hashes are not rewritten.

EIBO is designed for operation by one accountable human operator using automated execution, archival, hashing, quality-control, and export workflows. Automation does not approve protocol, provider-terms, or ethics/governance determinations. Each required determination still needs an explicit, attributable human record.

## Coding model

The primary coding record is produced by one human coder using a blind export and versioned coding provenance. EIBO does not claim inter-rater reliability from two independent human coders.

A second AI model is not required. If a future analysis enables AI secondary coding, it is an optional sensitivity analysis only. Its model ID, prompt, parameters, inputs, outputs, and hashes must be locked and preserved; it must be blind to the primary codes; its output remains separate; and it cannot replace the human coder, satisfy an independent-human-coder requirement, adjudicate disagreement, or overwrite primary codes.

## Applicability and limitation

The frozen MIBO-Education Codebook v1.0 requires at least two independent coders before W01. This amendment does not retroactively change that requirement and cannot make W01 executable. W01 also retains its historical identifiers and frozen September 2026 observation window.

A future official EIBO Wave must prospectively reference an approved and hash-locked scientific amendment or successor protocol that explicitly adopts this coding model. Until a named human completes `operations/operating-model-attestation.yaml`, the configuration is not an approval and does not authorize an official EIBO Wave.
