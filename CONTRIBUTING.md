# Contributing to MIBO

MIBO welcomes methodological criticism, replication proposals, coding corrections, documentation improvements, and compatible research extensions.

- Use issues for questions, defects, and proposals.
- Use pull requests for concrete, versioned changes.
- Preserve original records and change history.
- Distinguish confirmatory from exploratory work.
- Disclose material generative-AI use.
- Report deviations, errors, and nonreplications without concealment.
- Apply substantive protocol amendments prospectively.
